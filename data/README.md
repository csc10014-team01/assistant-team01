# Data Directory

Thư mục này chứa các file dữ liệu được sử dụng cho dự án Smart Virtual Assistant.

## Data Sources & Owners

### 1. `offices.csv`
File này lưu trữ thông tin liên hệ và vị trí của các phòng ban, dịch vụ trong khuôn viên trường.

* **Cấu trúc dữ liệu:**
  * `name`: Tên phòng ban (ví dụ: Training Office, Student Affairs,...).
  * `room`: Vị trí / Số phòng.
  * `hours`: Giờ làm việc trong tuần.
  * `phone`: Số điện thoại liên hệ.
* **Nguồn dữ liệu (Source):** Giả lập
* **Người quản lý (Owner):** Phạm Yến Trân
