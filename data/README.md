
# HCMUS Service Offices Dataset

## 1. Overview

This directory contains a **self-created sample dataset** of service offices at the University of Science (HCMUS).

The dataset is stored in `offices.csv` and includes office names, room locations, working hours, and contact phone numbers.

The dataset is maintained and updated throughout project development.

## 2. Data Source and Ownership

| File | Source | Owner | Update Frequency |
| --- | --- | --- | --- |
| `offices.csv` | Self-created sample data | Phạm Yến Trân | As needed, when records are added, modified, or corrected |

## 3. Dataset Structure

The `offices.csv` file currently contains **8 records** and **4 columns**.

| Column | Description | Example |
| --- | --- | --- |
| `name` | Name of the service office | `Training Office` |
| `room` | Room number or location | `I.101` |
| `hours` | Working days and hours | `Mon-Fri 07:30-16:30` |
| `phone` | Contact phone number | `0909090909` |

### Included Offices

- Training Office
- Student Affairs
- Library
- IT Helpdesk
- Health Centre
- Admissions Office
- Academic Affairs
- Finance Office
